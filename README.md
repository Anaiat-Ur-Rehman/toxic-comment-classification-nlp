# Multi-Class Toxic Comment Classification (NLP)

An end-to-end Natural Language Processing pipeline designed to classify textual comments into toxicity categories using Python.

## Features
- Text cleaning and regex-based text preprocessing.
- Inference script (`toxic_classifier.py`) for detecting toxicity categories (Non-Toxic, Toxic, Severe Toxic).
- Lightweight and mobile-friendly execution setup.
